# 旅行業務取扱管理者試験 学習・模擬試験サイト(本人用)

スマホで使う個人用の学習サイト。記録はブラウザの中(localStorage)だけに保存し、サーバーには送りません。

- そのまま読める問題: オリジナルのサンプル問題、観光庁「地域限定旅行業務取扱管理者試験」の過去問(法令・約款。公共データ利用規約 第1.0版に従い、問題ごとの分割・表記の調整・難易度の推定を加えて利用)
- 日本旅行業協会(JATA)の総合試験、全国旅行業協会(ANTA)の国内試験の過去問は、本人の学習用に合言葉で暗号化して置いています(data/locked/)。著作権は各協会に帰属します。複製・再配布はしないでください。
- 出典は各問題の下と「出典・試験の構成」に表示しています。
